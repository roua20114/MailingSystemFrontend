## Deploying to Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the repo in Vercel.
3. Leave the build command as `npm run build`.
4. Leave the output directory as `dist`.
5. Set `VITE_API_BASE_URL` in Vercel if your backend is not served from the same domain.

This project is a React SPA, so the included `vercel.json` rewrite sends all client-side routes to `index.html`.
